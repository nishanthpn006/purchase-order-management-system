# Project Vision — Purchase Order Management System (POMS)

## Executive Summary

The Purchase Order Management System (POMS) is a web-based enterprise procurement application designed to streamline vendor management, product catalog maintenance, purchase order processing, inventory level tracking, and goods receipt verification.

## Core Value Proposition

- **Automated Workflow**: Replaces manual purchase order workflows with a structured, role-based web interface.
- **Data Integrity**: Ensures strict relational integrity across vendors, products, purchase orders, inventory, and goods receipts using MySQL 8.
- **Security & Access Control**: Protects administrative features through JWT authentication and bcrypt password encryption.
- **Operational Visibility**: Provides real-time stats and metrics via an interactive React dashboard.

## Target Audience

- **Procurement Managers**: Responsible for vendor relationships and approving purchase orders.
- **Warehouse Staff**: Responsible for managing inventory levels and issuing goods receipts.
- **System Administrators**: Responsible for system administration and user management.
