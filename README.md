# 📦 Purchase Order Management System (POMS)

A full-stack **Purchase Order Management System (POMS)** built as a final-year capstone project following professional software engineering practices.

The application is designed to streamline the procurement process by enabling organizations to create, approve, track, and manage purchase orders through a secure, role-based workflow.

---

## 🎯 Project Vision

The goal of this project is to replace manual procurement processes such as spreadsheets, emails, and paper-based approvals with a centralized web application that improves transparency, efficiency, and traceability.

This project is being developed incrementally over **15 weeks**, following an industry-inspired software development lifecycle, with continuous GitHub commits, documentation, testing, and deployment.
